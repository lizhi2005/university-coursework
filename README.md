# 大学课程作业合集

本科阶段各门课程的实验代码与作业，按课程归档。

## 目录结构

| 目录 | 课程 | 内容 |
|---|---|---|
| `os-experiments/` | 操作系统 | C/C++ 实验进程管理、内存、文件系统等 |
| `ai-experiments/` | 人工智能 | Python 算法实验（搜索、推理等） |
| `bigdata-experiments/` | 大数据 | Hadoop/Spark 相关实验脚本 |
| `java/` | Java 程序设计 | Java 课程项目与练习 |
| `web/` | Web 开发 | HTML/CSS/JS 静态页面与课程作业 |
| `go/` | Go 语言 | Go 语言入门练习 |
| `homework-reports/` | 大数据挖掘 | 实验作业报告（Word） |
| `diercishixi/` | 二次实习 | 实习运行项目代码 |

> 说明：体积较大的可执行文件、数据集与依赖包未上传，实验报告仅保留部分。
